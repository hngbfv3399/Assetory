## 설계 변경사항

- 장바구니 수량 변경은 구현하지 않는다. Notion API 설계와 ERD의 `cart_items`에는 `quantity`가 없고, 디지털 상품은 수량을 관리하지 않는다고 명시되어 있다.
- Notion의 `POST /api/cart/items` 요청 본문은 비어 있다고 적혀 있지만 경로에 상품 식별자가 없어 실제 상품을 특정할 수 없다. 경로·Method는 유지하고 최소 보완으로 `{ "productId": number }` 요청 본문을 사용했다.
- Notion 일정의 5단계 상태는 `시작 전`이며 일정은 2026-07-31~08-01로 확인됐다. 사용자의 2026-07-27 착수 지시와 차이가 있지만, 승인 없이 Notion은 수정하지 않는다.
