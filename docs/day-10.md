# 10일차 작업일지

## 오늘의 목표

- 프론트 화면 작업을 보류하고, 백엔드 역할 정책의 재현 가능한 자동 검증과 실행·배포 문서를 완성한다.

## 구현 및 검증 결과

- `backend/scripts/test-collaborator-flow.sh`를 추가했다. 매 실행마다 소유자·관리자·편집자·조회자·제3자와 상품을 생성해 역할 초대·수락, 변경 요청 승인·반려, 직접 수정 차단, 상품 범위 주문·환불·문의·통계 접근, 미인증 차단을 15단계로 검증한다.
- 실제 로컬 서버에서 역할 승인 종단 스크립트 15단계 전체를 통과했다.
- 루트 README에 로컬 실행, 환경변수, Maven·종단 검증 명령, 역할 정책, 문서 위치를 추가했다.
- `docs/deployment.md`에 운영 비밀값, DB 주의사항, 빌드·기동, 배포 후 검증, 완료 기준을 정리했다.

## 범위 보류

- React 운영 화면과 shadcn/ui 도입은 사용자 요청으로 보류했다.
- 실제 원격 배포는 대상 플랫폼·계정·도메인·운영 DB가 제공되지 않아 수행하지 않았다.
