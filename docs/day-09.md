# 9일차 작업일지

## 오늘의 목표

- 판매자가 주문·환불 데이터를 기준으로 매출, 고객, 상품별 실적과 예상 정산액을 확인할 수 있게 한다.

## 구현 및 검증 결과

- 대시보드 요약, 기간별 매출, 상품별 판매 통계, 예상 정산 API를 구현했다.
- 결제 완료 주문 항목은 결제 완료 시각으로 매출·판매 건수·구매 고객을 집계하고, 완료된 환불은 환불 완료 시각으로 별도 차감한다.
- 상품별 통계는 순매출·판매 건수·환불률 정렬과 페이지네이션을 제공한다.
- 예상 정산은 순매출에서 플랫폼 수수료 10%를 차감한 `ESTIMATED` 결과만 반환하며 실제 송금은 구현하지 않는다.
- 실제 Mock 결제 주문 1건으로 총매출 10,000원, 수수료 1,000원, 예상 정산 9,000원을 curl로 검증했다.
- 컴파일과 `.env`를 로드한 Maven 테스트를 통과했다.

## 설계 보완

- Notion 판매 통계 API에는 예상 정산 엔드포인트가 없었지만, 9단계 완료 기준의 수수료·예상 정산 계산을 충족하기 위해 `GET /api/seller/statistics/settlement`를 추가했다.
- 플랫폼 수수료율은 설계에 수치가 없어 최소 가정으로 10%를 적용했다. 실제 송금·정산 상태 변경은 범위 밖이다.
