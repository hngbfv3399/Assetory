## 해결한 문제

- 문제점: 실행 스크립트에 `--server.port=8081`을 직접 전달하면 Maven 옵션으로 해석돼 서버가 시작하지 않았다.
- 원인: Spring Boot 애플리케이션 인자 전달 방식이 Maven 실행 인자와 다르다.
- 해결 방법: `ASSETORY_SERVER_PORT` 환경변수를 `spring-boot.run.arguments`로 전달하도록 수정했다.

## 설계 변경사항

- 공개 후기 조회를 위해 3단계에서는 `Review.orderItemId`를 값으로 보관한다.
- 이유: 후기의 구매 완료 검증에 필요한 `OrderItem` 도메인은 6단계 범위이며, 지금 구현하면 단계 경계를 넘는다.
- 6단계에서 `OrderItem` 연관관계로 전환하고, 7단계 후기 작성에서 구매 이력과 주문 항목당 한 건 규칙을 검증한다.
