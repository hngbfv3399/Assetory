## 해결한 문제

- MySQL root 비밀번호를 잊어 접속이 불가능했다.
  - root 계정 비밀번호를 재설정한 뒤 애플리케이션 전용 DB 계정을 만들었다.
- Spring Boot 실행 중 8080 포트 충돌이 발생했다.
  - 이미 실행 중인 서버의 헬스 체크 API를 호출해 정상 동작 중임을 확인하고, 중복 실행하지 않았다.
- 인증 흐름 테스트의 리프레시 토큰 요청에서 `curl` 옵션이 줄바꿈에 의해 잘못 해석됐다.
  - 스크립트의 명령 구성을 수정한 뒤 전체 테스트를 재실행해 통과를 확인했다.

- 사용자 역할을 단일 값이 아닌 `user_roles` 컬렉션으로 구성했다.
  - 한 회원이 구매자와 판매자 기능을 모두 사용하고 화면을 전환하는 서비스 정책을 반영했다.
- `users`에 선택적 `profile_image_url` 필드를 추가했다.
  - 확정된 내 정보 수정 API의 `profileImageUrl` 요청·응답을 저장하기 위해 필요했다.
